

## 手工安装

核心准备：建立一个简单的专属文件夹

在开始下载前，**强烈建议**在 C 盘根目录建一个名字最简单的文件夹，比如 `C:\Store`。把接下来下载的所有文件都塞进这里，这会让你等会儿敲代码时轻松十倍。

------

### 第一步

你需要哪些安装包？（去哪里下载）

请打开网页：**[store.rg-adguard.net](https://store.rg-adguard.net/)** （这是一个专门从微软官方服务器解析直链的网站）。

- 左侧下拉框选择：`ProductId`
- 中间输入框填入：**`9WZDNCRFJBMP`** （这是微软商店的产品ID）
- 右侧下拉框选择：`Retail`（正式版通道）
- 点击右侧的 **✓** 按钮。

页面会加载出非常长的一大串列表。你需要从里面“淘”出以下 **5 个** 文件（请务必看准名字、架构和后缀）：

#### 🛠️ 必备依赖包（4个）

这四个是地基，必须下。**（找列表中带有 `_x64_` 且后缀是 `.appx` 的文件）**

1. **VCLibs (UWPDesktop)**
   - **全名类似：** `Microsoft.VCLibs.140.00.UWPDesktop_14.0.33728.0_x64__8wekyb3d8bbwe.appx`
   - **核心注意一：** 版本越高越好，直接找列表里数字最大的。
   - **核心注意二：** 一定要下载中间带有 `UWPDesktop` 字段，尾部带有 `appx` 字段的包！
   - 如果上面的网站 `https://store.rg-adguard.net/` 漏了这个包，
     可以直接点击或复制这个微软官方直链进行下载：
     👉 https://aka.ms/Microsoft.VCLibs.x64.14.00.Desktop.appx
   
     (这是一个以 aka.ms 开头的微软官方短链接，非常安全，它会始终指向最新版的 x64 UWPDesktop 运行库，版本绝对满足 33728.0 以上的要求。)
2. **UI.Xaml**
   
   - **全名类似：** `Microsoft.UI.Xaml.2.8_8.2501.31001.0_x64__8wekyb3d8bbwe.appx`
   - 挑版本号最大的（目前通常是 2.8 系）。
3. **.NET Native Framework**
   - **全名类似：** `Microsoft.NET.Native.Framework.2.2_2.2.29512.0_x64__8wekyb3d8bbwe.appx`
4. **.NET Native Runtime**
   - **全名类似：** `Microsoft.NET.Native.Runtime.2.2_2.2.28604.0_x64__8wekyb3d8bbwe.appx`

#### 🛍️ 微软商店本体（1个）

这是你要盖的楼。**（找列表中带有 `neutral` 且后缀是 `.msixbundle` 或 `.appxbundle` 的文件）**

1. **Windows Store 本体**
   - **全名类似：** `Microsoft.WindowsStore_22405.1401.3.0_neutral_~_8wekyb3d8bbwe.Msixbundle`
   - 往下翻，找文件体积最大的那几个之一（通常有几十MB），挑一个最新的。

------

### 第二步

下载时的避坑指南（需要注意什么？）

1. **无视杂鱼文件：** 列表里会有很多 `.BlockMap` 和 `.eappx` 结尾的文件，**千万不要下**，毫无用处。
2. **避开其他架构：** 你是 64 位系统，只认准包含 `_x64_` 的依赖包。不要下 `_x86_` 或 `_arm_`，装不上的。
3. **浏览器拦截问题：** 点击这些链接时，浏览器（尤其是 Edge 或 Chrome）可能会提示“无法安全下载”或拦截。这是因为文件是 `.appx` 格式。你需要点击“保留”或“仍然保留”。这是从微软官方 `microsoft.com` 服务器拉取的，绝对安全。

------

### 第三步

严格的安装顺序

把这 5 个文件都放进 `C:\Store` 文件夹后。**右键开始菜单 -> Windows PowerShell (管理员)**。

**铁律：必须先装 4 个依赖，最后装 1 个商店本体。**

#### 方法一：

依次输入以下指令（请根据你实际下载的文件名替换引号里的内容）：

PowerShell

```
# 1. 安装 VCLibs (最容易报错的那个，最先装它)
Add-AppxPackage -Path "C:\Store\Microsoft.VCLibs.140.00.UWPDesktop_你要填入对应的版本号_x64__8wekyb3d8bbwe.appx"

# 2. 安装 UI.Xaml
Add-AppxPackage -Path "C:\Store\Microsoft.UI.Xaml.2.8_你要填入对应的版本号_x64__8wekyb3d8bbwe.appx"

# 3. 安装 .NET Native Framework
Add-AppxPackage -Path "C:\Store\Microsoft.NET.Native.Framework.2.2_你要填入对应的版本号_x64__8wekyb3d8bbwe.appx"

# 4. 安装 .NET Native Runtime
Add-AppxPackage -Path "C:\Store\Microsoft.NET.Native.Runtime.2.2_你要填入对应的版本号_x64__8wekyb3d8bbwe.appx"
```

*小技巧：在 PowerShell 里，你输入 `Add-AppxPackage -Path "C:\Store\M` 之后，按键盘上的 `Tab` 键，它会自动帮你补全文件名，按多次 `Tab` 可以切换不同的文件，不用手敲那一长串乱码！*

确保上面四行指令敲完后，都没有出现你之前那种红色的“部署失败”错误，那么就可以执行最后一步决战了：

PowerShell

```
# 5. 最后安装商店本体
Add-AppxPackage -Path "C:\Store\Microsoft.WindowsStore_你要填入对应的版本号_neutral_~_8wekyb3d8bbwe.Msixbundle"
```

如果没有红字，按下 Windows 徽标键，你就会看到熟悉的 Microsoft Store 图标了。如果在下载文件或输入指令的过程中卡住了，随时告诉我！



#### 方法二：

如果你不想手动一行一行去敲长长的文件名，我们可以把你的思路**稍微改造一下，拆成两步**。这既保留了自动化的爽快感，又保证了 100% 的成功率。

请确保你已经通过 `cd` 指令进入了存放安装包的文件夹（比如 `cd C:\Store`），然后依次粘贴执行以下两行代码：

**第一步：先批量安装所有依赖包（打地基）**

PowerShell

```
Get-ChildItem *.appx | ForEach-Object { Add-AppxPackage -Path $_.FullName }
```

*(这行指令会把文件夹里所有后缀为 `.appx` 的基础运行库全部装上。这四个依赖包之间没有先后顺序要求，所以批量安装非常安全。)*

**第二步：最后安装商店本体（盖大楼）**

PowerShell

```
Get-ChildItem *.msixbundle | ForEach-Object { Add-AppxPackage -Path $_.FullName }
```

*(因为文件夹里只有商店本体是 `.msixbundle` 格式，这行指令会确保它在所有地基打好之后，作为压轴出场。)*

这样操作，既不用手动补全乱码般的文件名，又能完美避开恼人的依赖项冲突！你可以试试这个方案。

## 脚本安装

> 注意：脚本生成后还未实践检验！

它会自动在 C:\Store 创建目录、从 GitHub 下载完整依赖包、解压并自动唤起安装流程。

Install_Microsoft_store.ps1

> 保险起见，我脚本保存时转换为了 UTF-8 with BOM 格式！

```
# ==========================================
# 0. 强制接管控制台编码 (彻底解决中文乱码)
# ==========================================
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::InputEncoding  = [System.Text.Encoding]::UTF8
$OutputEncoding           = [System.Text.Encoding]::UTF8

# ==========================================
# 1. 管理员权限检查与自动提权
# ==========================================
$isAdmin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
if (!$isAdmin) {
    Write-Host "正在请求管理员权限..." -ForegroundColor Yellow
    Start-Process powershell.exe -ArgumentList "-NoProfile -ExecutionPolicy Bypass -File `"$PSCommandPath`"" -Verb RunAs
    exit
}

# ==========================================
# 2. 环境准备
# ==========================================
$WorkPath = "C:\Store_Installer"
if (!(Test-Path $WorkPath)) { New-Item -ItemType Directory -Force -Path $WorkPath | Out-Null }
Set-Location $WorkPath

# 开启 TLS 1.2
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

# ==========================================
# 3. 核心下载配置 (多镜像轮询)
# ==========================================
$RawUrl = "https://github.com/kkkgo/LTSC-Add-MicrosoftStore/archive/refs/heads/master.zip"
# 备用镜像列表
$Mirrors = @(
    "https://mirror.ghproxy.com/",        # 推荐：最稳定
    "https://ghps.cc/",                   # 备选1
    "https://gh.api.99988866.xyz/",        # 备选2
    ""                                    # 最后尝试直连 (适合开启 VPN 时)
)

$ZipFile = "MicrosoftStore_LTSC.zip"
$DownloadSuccess = $false

Write-Host "--- 开始下载微软商店工具包 (文件较大，请耐心等待) ---" -ForegroundColor Cyan

foreach ($Mirror in $Mirrors) {
    $TargetUrl = $Mirror + $RawUrl
    try {
        if ($Mirror -eq "") { Write-Host "尝试 GitHub 官方直连..." -ForegroundColor Gray }
        else { Write-Host "尝试加速镜像: $Mirror" -ForegroundColor Gray }
        
        # 使用 -ErrorAction Stop 触发 catch
        Invoke-WebRequest -Uri $TargetUrl -OutFile $ZipFile -TimeoutSec 300 -ErrorAction Stop
        
        # 检查下载的文件是否过小 (如果只有几KB通常是下载了错误页面)
        if ((Get-Item $ZipFile).Length -gt 1MB) {
            Write-Host "成功下载安装包！" -ForegroundColor Green
            $DownloadSuccess = $true
            break
        }
    } catch {
        Write-Host "当前镜像连接超时或失败，准备切换..." -ForegroundColor Yellow
        if (Test-Path $ZipFile) { Remove-Item $ZipFile -Force }
    }
}

if (!$DownloadSuccess) {
    Write-Host "所有镜像均下载失败！请检查您的网络连接或开启 VPN。" -ForegroundColor Red
    Pause
    exit
}

# ==========================================
# 4. 解压与安装
# ==========================================
Write-Host "正在解压安装包..." -ForegroundColor Cyan
if (Test-Path ".\LTSC-Add-MicrosoftStore-master") { Remove-Item ".\LTSC-Add-MicrosoftStore-master" -Recurse -Force }
Expand-Archive -Path $ZipFile -DestinationPath ".\" -Force

# 查找解压后的 cmd 文件
$InstallerCmd = Get-ChildItem -Path ".\LTSC-Add-MicrosoftStore-master\Add-Store.cmd" -ErrorAction SilentlyContinue

if ($InstallerCmd) {
    Write-Host "准备执行安装程序。请在弹出的黑色窗口中等待完成。" -ForegroundColor Yellow
    # 使用 Start-Process 并在完成后等待
    Start-Process -FilePath "cmd.exe" -ArgumentList "/c `"$($InstallerCmd.FullName)`"" -Wait
    
    Write-Host "=========================================" -ForegroundColor Green
    Write-Host "执行结束！请查看开始菜单是否出现了 Store。" -ForegroundColor Green
    Write-Host "注意：如果安装后闪退，请重启电脑后再试。" -ForegroundColor Green
    Write-Host "=========================================" -ForegroundColor Green
} else {
    Write-Host "解压后的目录结构异常，未找到 Add-Store.cmd。" -ForegroundColor Red
}

# 可选清理
# Remove-Item $ZipFile -Force
Write-Host "按任意键退出..."
$null = $Host.UI.RawUI.ReadKey("NoEcho,IncludeKeyDown")
```
